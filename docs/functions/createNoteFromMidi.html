    Function createNoteFromMidi

    • createNoteFromMidi(options: CreateNoteFromMidiOptions): Note

      Creates a Note object from a standard MIDI note number (0-127). Determines the letter, accidental, and octave based on the MIDI value. Allows specifying enharmonic preference for ambiguous cases (like MIDI 61: C# or Db).

      Parameters

      • options: CreateNoteFromMidiOptions

        An object containing the MIDI number and optional settings. See CreateNoteFromMidiOptions.

      Returns Note

      The created Note object.

      Throws

      If the MIDI number is outside the valid range (0-127).

      Example

      const a4_sharp = createNoteFromMidi({ midi: 69 }); // Defaults to sharp preference -> A4
      const a4_flat = createNoteFromMidi({ midi: 69, prefer: 'flat' }); // Still A4 (no enharmonic ambiguity)

      const cs4_sharp = createNoteFromMidi({ midi: 61 }); // Defaults to sharp -> C#4
      const db4_flat = createNoteFromMidi({ midi: 61, prefer: 'flat' }); // -> Db4

      const midi60_plus30c = createNoteFromMidi({ midi: 60, cents: 30 }); // C4 + 30 cents
