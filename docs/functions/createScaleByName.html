    • createScaleByName(
          root: string | Note,
          name: ScaleName,
          options?: Partial<ScaleOptions>,
      ): Scale

      Creates a Scale object using a predefined scale name and a root note, which can be provided as a Note object or a string (e.g., "C4", "Bb3"). This is a convenience wrapper around createScale.

      Parameters

      • root: string | Note

        The root of the scale, either as a Note object or a string representation (e.g., "C4", "F#5").

      • name: ScaleName

        The name of the desired scale (e.g., "major", "dorian", "minorPentatonic"). Must exist in SCALE_PATTERNS.

      • Optionaloptions: Partial<ScaleOptions> = {}

        Optional settings to override defaults. See ScaleOptions. Passed down to createScale.

      Returns Scale

      The created Scale object.

      Throws

      If the root note object/string is invalid or the scale name is unknown.

      Example

      // Create C Major scale with root as string
      const cMajor = createScaleByName("C4", "major");

      // Create F# Minor scale with specific preference
      const fSharpMinor = createScaleByName("F#3", "minor", { prefer: 'sharp' });
