    • createJustIntonationNote(
          referenceNote: Note,
          ratio: string | number,
          options?: { includeCachedValues?: boolean; prefer?: EnharmonicPreference },
      ): MicrotonalNote

      Creates a microtonal Note based on a Just Intonation ratio relative to a reference note. Parses ratios provided as strings (e.g., "3/2", "5/4") or uses numeric ratios directly. Looks up common ratios in JUST_INTONATION_RATIOS. The resulting note is marked with the 'justIntonation' tuning system and will likely have a cents property indicating its deviation from the nearest 12-TET pitch.

      Parameters

      • referenceNote: Note

        The Note object to use as the base (representing the 1/1 ratio).

      • ratio: string | number

        The Just Intonation ratio to apply, either as a number (e.g., 1.5) or a string (e.g., "3/2", "5/4"). Must result in a positive value.

      • Optionaloptions: { includeCachedValues?: boolean; prefer?: EnharmonicPreference }

        Optional parameters for note creation.

        • OptionalincludeCachedValues?: boolean

          Whether to include cached values (midi, notation, frequency) on the returned note object.

        • Optionalprefer?: EnharmonicPreference

          Preferred spelling for the resulting note when determining letter/accidental from frequency.

      Returns MicrotonalNote

      A MicrotonalNote object representing the pitch derived from the ratio.

      Throws

      If the reference note is invalid.

      Throws

      If the ratio format is invalid, cannot be parsed, or results in a non-positive value.

      Example

      const c4 = createNote({ midi: 60 }); // Reference note

      // Create a Just Major Third above C4 using string ratio "5/4"
      const e4_just = createJustIntonationNote(c4, "5/4");
      // -> E4 with cents ≈ -13.69 compared to equal temperament
      console.log(formatNote(e4_just), e4_just.cents?.toFixed(2)); // "E4", "-13.69"

      // Create a Just Perfect Fifth using numeric ratio 1.5
      const g4_just = createJustIntonationNote(c4, 1.5);
      // -> G4 with cents ≈ +1.96 compared to equal temperament
      console.log(formatNote(g4_just), g4_just.cents?.toFixed(2)); // "G4", "1.96"
