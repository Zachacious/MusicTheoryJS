    Function centsToRatio

    • centsToRatio(cents: number): number

      Converts an interval measured in cents into a frequency ratio. For example, 1200 cents (an octave) yields a ratio of 2.0. 700 cents (approx perfect fifth) yields a ratio of ~1.5.

      Parameters

      • cents: number

        The interval size in cents.

      Returns number

      The corresponding frequency ratio multiplier.

      Example

      const octaveRatio = centsToRatio(1200); // 2.0
      const p5Ratio = centsToRatio(701.955); // Approximately 1.5 (3/2)
      const m3Ratio = centsToRatio(300);     // Approximately 1.189 (2^(3/12))
