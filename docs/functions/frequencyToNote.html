    Function frequencyToNote

    • frequencyToNote(
          frequency: number,
          options?: { includeCachedValues?: boolean; prefer?: EnharmonicPreference },
      ): Note

      Converts a frequency in Hertz (Hz) to the nearest Note object in the standard 12-tone equal temperament system. Calculates the cents deviation from the determined note's exact pitch.

      Parameters

      • frequency: number

        The frequency value in Hz. Must be positive.

      • Optionaloptions: { includeCachedValues?: boolean; prefer?: EnharmonicPreference }

        Optional parameters.

        • OptionalincludeCachedValues?: boolean

          If true, includes calculated midi, notation, frequency, and cents properties on the returned object.

        • Optionalprefer?: EnharmonicPreference

          Preferred spelling ('sharp' or 'flat') for enharmonically ambiguous notes.

      Returns Note

      A Note object representing the nearest 12-TET pitch, potentially including a cents property indicating the deviation.

      Throws

      If the frequency is non-positive or results in an out-of-range MIDI value.

      See

      createNoteFromFrequency which is used internally.

      Example

      const noteA4 = frequencyToNote(440); // Creates A4, cents ≈ 0
      console.log(formatNote(noteA4), noteA4.cents); // "A4", 0 (approx)

      const noteA4Sharpish = frequencyToNote(442); // Creates A4, cents ≈ +7.8
      console.log(formatNote(noteA4Sharpish), noteA4Sharpish.cents?.toFixed(1)); // "A4", "7.8"

      const noteDb4 = frequencyToNote(270, { prefer: 'flat' }); // Creates Db4, cents ≈ -38.9
      console.log(formatNote(noteDb4), noteDb4.cents?.toFixed(1)); // "Db4", "-38.9"
