      Applies a specified harmonic transformation to a chord progression. Supports basic examples of substitution, extension, secondary dominant insertion, and modal interchange. Requires a Scale context for some transformations.

      Parameters

      • progression: ChordProgression

        The input ChordProgression (array of Chord objects or symbols).

      • transformation: "substitute" | "extend" | "secondary-dominant" | "modal-interchange"

        The type of transformation to apply:

        • "substitute": Example: Replaces V7 with vii°7 (basic example).
        • "extend": Example: Converts triads to corresponding seventh chords.
        • "secondary-dominant": Inserts V7/x chords before non-tonic target chords (requires options.scale).
        • "modal-interchange": Example: Borrows chords from the parallel major/minor key (requires options.scale).
      • Optionaloptions: Partial<ChordOptions & { scale?: Scale }> = {}

        Optional settings.

        • scale

          The Scale object providing the key context, required for 'secondary-dominant' and 'modal-interchange'.

        • prefer

          Enharmonic preference for created chords.

        • includeCachedValues

          Cache flag for notes in created chords.

      Returns ChordProgression

      A new ChordProgression array containing the transformed sequence. The original progression is not modified.

      Throws

      If the input progression is invalid or required options (like scale) are missing for a transformation.

      Remarks

      The implementations for transformations provided in the original code are basic examples and may need significant expansion for comprehensive harmonic manipulation. Error handling for chord creation within transformations should be considered.
